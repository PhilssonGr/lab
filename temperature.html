Temperature

1 What it is

Temperature is a number a request can send with the prompt. It changes how the next token is picked. Lower makes the leading candidate more dominant. Higher gives less likely candidates more of a chance. The allowed range is not the same on every model, and some current models ignore a custom value or reject it.

1.0

Three fixed scores, named ship, send, and hold. The picture divides each score by the slider and rescales the three results so they fill the bars. It is not a provider sampler, and these words are not model output.

2 Why it matters

Cost

Temperature is not its own charge. The bill is still the tokens the request reads and writes. You pay more only if the setting makes the reply longer or makes you send the request again.

Quality

Lower keeps the reply closer to the leading candidate, which often fits a fixed shape. Higher lets less likely tokens through, which varies the wording. Gemini's prompting guide says earlier Gemini 3 models should keep the default, and that Gemini 4 and Gemini 3.6+ ignore a custom temperature.

Risk

A low temperature can still produce a confident wrong sentence. Anthropic's Messages API says that even 0.0 is not fully deterministic on models that accept it. OpenAI says to change temperature or top_p, not both.

3 How to apply · try today

Take a prompt you already send. If the model accepts temperature, run it once at the default and once lower, and change nothing else. See whether the reply stays in the shape you asked for.

Common mistake

Using a low temperature as a fact check, or expecting one number to mean the same thing on every model.

Questions

What is temperature?
Temperature is a sampling control that shifts how often less likely next tokens are picked.
Does a lower temperature check that a reply is true?
No. It changes which next token is more likely. It does not add a source, and a low setting is not a promise that the reply stays the same.
Do all current models accept a custom temperature?
No. OpenAI documents a range from 0 to 2. Anthropic documents 0.0 to 1.0 on models that still accept it, and says models released after Claude Opus 4.6 reject any value other than 1.0. Gemini's prompting guide says Gemini 4 and Gemini 3.6+ ignore a custom temperature.
