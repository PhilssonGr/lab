Tokens

Tokens are the pieces of text a model reads, writes, and bills for.

The unit models read, write, and bill in.

Last checked 2026-10-16 Free card 4 min

Ask about Tokens

What changed

Oct 16: Cost now covers output versus input, cached input, and a higher rate past a size threshold, in general terms. The common mistake is that the same text is not the same token count on every model.

1 What it is

Models don't see words. They see tokens: chunks of text, often parts of words. Every prompt and every reply is counted in tokens.

0 tokens · 0 chars

Two illustrations. A word longer than the split size is cut into slices. Spaces and punctuation are their own chips. A provider tokenizer will not match either count, and two models can disagree.

2 Why it matters

Cost

Hosted models bill by token, but not every token costs the same. Output usually costs more than input. Cached input can be much cheaper. Some models charge a higher rate once a prompt passes a size threshold.

Quality

Tokens spent on leftover instructions are tokens the reply cannot use.

Risk

Anything you paste is sent as tokens, including keys, customer text, and private notes.

3 How to apply · try today

Paste one real prompt into your provider's token counter. Note the input and output tokens, then multiply by the current rates. That gives you the cost per run.

Common mistake

Assuming the same text is the same number of tokens on every model. Tokenizers change between model versions.

Questions

What is a token?
Tokens are the pieces of text a model reads, writes, and bills for. A token is often part of a word, not the whole word.
Is the same text the same number of tokens on every model?
No. Tokenizers change between models and between versions of a model.
What can happen to the input rate past a size threshold?
Some models charge a higher rate once a prompt passes a size threshold.
